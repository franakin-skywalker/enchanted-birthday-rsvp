# Enchanted Birthday RSVP

A fantasy-themed birthday invitation website designed to give guests an interactive, immersive way to explore an event and respond to an invitation.

## Project overview

Created for my 28th birthday celebration, this project combines an enchanted visual theme with event information, fantasy-inspired artwork, and an RSVP experience.

## Features

- Fantasy-inspired visual design
- Custom imagery and creature-themed artwork
- Interactive invitation experience
- Music toggle
- Responsive layout for different screen sizes

## Technologies

- HTML
- CSS
- JavaScript

## What I learned

This project gave me an opportunity to explore web design, interactive user experiences, visual hierarchy, and the way design can shape how users engage with information.

## Future improvements

- Test and refine the mobile experience
- Improve accessibility and keyboard navigation
- Document the user journey and design decisions
- Conduct usability testing and iterate based on feedback
